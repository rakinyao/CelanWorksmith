# CelanWorkshop 占位品牌替换设计

## 目标

将当前对外可见的 Appsmith 默认品牌替换为 CelanWorkshop（中文名：沧澜工坊）的首期占位品牌。该工作建立可替换的本地默认资产，不改变内部 `CelanWorksmith` 包名、服务名、数据模型或执行路径。

## 品牌方向

- 标记：青绿色方形 `C` 标记，表达“沧澜”而不复用 Appsmith 图形。
- 主色：`#0E7490`。
- 英文名：`CelanWorkshop`。
- 中文名：`沧澜工坊`。
- 字标策略：英文名和中文名在 HTML 与邮件模板中以文本排版；图形标记、favicon 和小尺寸图标使用本地位图资产。文本不得嵌入生成的图片，以保证双语文字和无障碍名称准确。

## 实现边界

### 默认资产与主题

新增本地、版本可控的 CelanWorkshop 图形标记，提供透明底的常规标记、浅色反差版本和符合浏览器要求的 favicon。客户端的默认 Logo URL、favicon URL、默认品牌主色和默认背景色改为这些本地资源；现有管理员 Branding 配置仍可在运行时覆盖默认值。

### 用户可见入口

本期覆盖以下入口：

1. 编辑器与应用壳页首。
2. 登录、注册、初始化和其他身份认证页面。
3. 应用查看页的品牌角标。
4. 浏览器 favicon、公共 404 页和管理员 Branding 预览。
5. 系统邮件中的验证、邀请和密码重置模板。

页面中出现品牌名时，使用 `CelanWorkshop` 与“沧澜工坊”的可访问文本；仅空间不足的图标位置可只显示 `C` 标记，并提供可访问名称。

### 不在范围内

- Java、TypeScript、包名、服务名和已有 API 中的 `Appsmith` 或 `CelanWorksmith` 技术标识。
- 第三方数据源、插件和集成图标。
- 历史测试夹具、变更日志和法律条款中与上游 Appsmith 相关的历史或法律文本。
- 后续正式品牌规范、商标申请、动态多租户品牌策略。

## 资产与渲染原则

图形标记以独立源资产保存，并派生为页面 Logo 与 favicon 所需尺寸。浏览器 favicon 不依赖远程 CDN。邮件使用绝对可访问的部署资产地址或内联兼容资源，且不得再引用 `assets.appsmith.com` 的 Appsmith Logo。

任何 Logo 图片均需含有准确 `alt` 文本；仅作装饰的重复图形须标记为装饰，避免读屏器重复朗读品牌名。

## 验证

1. 客户端默认品牌配置单元测试验证本地 Logo、favicon 和 `#0E7490` 主色。
2. 核心页组件测试验证默认标记或文本品牌名的可访问名称。
3. 邮件模板检查确保不再引用 Appsmith Logo CDN。
4. 检查 favicon 文件格式和尺寸满足当前客户端限制。
5. 使用本地服务在浅色认证页、深色编辑器页和应用查看页进行截图验证，确认图标不失真、文字不溢出且管理员自定义 Branding 仍可覆盖默认样式。
