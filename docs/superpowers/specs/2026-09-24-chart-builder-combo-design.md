# ChartWidget 组合图 Builder 设计

## 目标与范围

在现有 `CHART_WIDGET` 中增加 `COMBO_CHART`，让同一张图的各条 `chartData` 序列分别以柱形或折线展示。组合图使用现有类别 X 轴和一条共享的数值 Y 轴，不引入新 Widget、第二条 Y 轴、不同单位、混合堆叠、主题或新的数据源。全柱形或全折线也是有效配置。

现有基础图表、Custom ECharts iframe 和历史 Custom Fusion 配置保持原有行为；`chartType`、`chartData`、`selectedDataPoint` 和 `onDataPointClick` 的既有字段与事件名称不迁移、不重命名。

## 序列契约与兼容性

在每条现有序列上增加可选字段 `seriesType?: "bar" | "line"`，与 `seriesName`、`data`、`color` 同级。字段只在 `COMBO_CHART` 模式生效；缺失时视为 `bar`。切换到组合图或离开组合图均不批量写入、移除或转换已有序列字段，切回其他图表后原始数据仍在。组合图模式中新建序列的 `seriesType` 默认为 `bar`，用户显式改为折线时写入 `line`。所有非组合图类型忽略该字段，不改变已有柱状图、折线图、堆叠图等的选项。

组合图仍用现有按类别对齐的 dataset，每条序列以相应的 ECharts `bar` 或 `line` 类型消费其原有维度，不重新排序或重新解释数据。现有系列名称、颜色、标签、标题、图例、滚动和坐标轴名称设置继续适用。组合图序列不设置 `stack`，不能通过该类型创建混合堆叠。X/Y 标签布局遵循现有竖向类别图规则。

## 编辑与异常处理

图表类型下拉增加组合图选项；`ChartDataControl` 仅在组合图模式为每条序列显示“展示类型”选择（柱形/折线），并复用现有序列编辑流程。新文案进入已有 `en-US` 和 `zh-CN` i18n 资源，存储值及 DSL 字段名保持英文。切换类型时不自动修改序列或强制生成缺失的 `seriesType`。

若组合图模式中某条序列显式提供的 `seriesType` 不是 `bar` 或 `line`，使用 ChartWidget 现有错误展示组件指出序列和字段；不得静默回退或覆写数据。缺省字段合法且按 `bar` 渲染。此校验只作用于组合图，离开组合图后错误消失；现有空数据状态和绑定/语法错误优先级不变。

## 交互与验证

组合图继续用基础 ECharts 点击事件的类别行与序列索引提取实际 `{ x, y, seriesTitle }`，不增加公开事件或更改 `selectedDataPoint` 的结构。图表类型在基础图之间切换时，已保存的 `chartData` 序列和点击处理保持一致。

单元和组件测试覆盖：旧序列缺省柱形、新建序列默认柱形、单条序列切换为折线、多序列混合及全同类型、组合图与现有图表相互切换不改写数据、仅组合图校验非法类型、图例/轴/颜色/标签继承，以及两种序列的点击事件。运行 ChartWidget 定向回归与 i18n 资源一致性测试；在编辑器中人工验证从已有多序列图切入组合图、切换单条序列类型、保存/重新打开和切回原图的效果。
