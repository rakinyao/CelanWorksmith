# v0.1.0 Ontology Integration Phase Release

**Status:** phase release record
**Date:** 2026-10-22
**Branch:** `feat/ontology-datasource-plugin`
**Release boundary:** committed content on the branch. The release-note
commit is the only change produced by this task; an annotated tag is a later
publication step.

This phase records the CelanWorksmith consumer handoff for the current
`ontology-model` Release JSON v2 contract. The normative contract is in
[`ontology-model-release-contract-handoff.md`](../ontology/ontology-model-release-contract-handoff.md),
with source-linked implementation evidence in
[`2026-10-22-ontology-platform-handoff-evidence.md`](../superpowers/verification/2026-10-22-ontology-platform-handoff-evidence.md).

## Included committed scope

The phase includes these committed capability areas, all through the native
Appsmith datasource, query, Action, and application-release paths:

- Ontology datasource and query integration, including plugin configuration,
  query validation, runtime provider resolution, and immutable metadata
  snapshot pinning.
- Release JSON v2 import, mapping, digest/identity validation, and immutable
  snapshots. The checked-in basic, Function, and Action fixtures are the
  consumer examples.
- Native Functions and Actions, including their current provisional metadata,
  ownership and target-bound checks, and the existing Action adapter boundary.
- Release preflight compatibility checks and application-release datasource
  pin extraction, with explicit snapshot/version compatibility diagnostics.
- Chinese page names and URL identity handling through the native page naming,
  slug, publication, and routing paths.
- Widget property-pane and editor localization through the existing i18n
  resources.
- Chart/ECharts improvements, including chart type and combo-chart behavior.
- Map Chart China boundary resources and application-owned GeoJSON map
  resources, including immutable resource references and the native publish/view
  path described by
  [`map-chart-campus-buildings-manual-test.md`](../superpowers/fixtures/map-chart-campus-buildings-manual-test.md).

The phase does not add a parallel ontology state or execution path. Function
and Action support remains the fixture-backed, provisional consumer behavior
described in the handoff; the separate Capability Release and production
Action Server proposal is outside this release contract.
